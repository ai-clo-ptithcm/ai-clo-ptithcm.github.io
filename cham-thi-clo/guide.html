HƯỚNG DẪN CHẤM THI CLO

Chấm dữ liệu UnT và tổng hợp kết quả theo CLO

Trang này hướng dẫn đúng quy trình hiện tại của công cụ Chấm thi CLO: tải nhiều file UnT, dùng đáp án từ Excel hoặc nhập trực tiếp, kiểm tra SBD/mã đề, ghép file khảo thí nếu có và xuất ba file kết quả.

1. Chuẩn bị dữ liệu

Công cụ có ba vùng nhập dữ liệu. Hai vùng đầu là dữ liệu chính, vùng thứ ba là tùy chọn.

  1. File UnT: chọn một hoặc nhiều file Excel kết quả cùng lúc.
  2. Đáp án + CLO: dùng file Excel hoặc nhập trực tiếp trên khung dạng bảng.
  3. File khảo thí: không bắt buộc; dùng khi cần ghép kết quả theo danh sách/phòng thi.
Nên giữ nguyên cấu trúc file UnT. Hệ thống sẽ tự tìm vùng dữ liệu cần thiết và đọc các cột SBD, mã đề, câu trả lời.

2. Đáp án + CLO

Cách 1 — Tải file Excel

Chọn file đáp án rồi nhấn Xem / xác nhận đáp án để kiểm tra trước khi chấm.

Cách 2 — Nhập trực tiếp

Chọn Nhập trực tiếp, nhập số câu, chọn kiểu bảng Dọc/Ngang rồi điền hoặc dán dữ liệu từ Excel.

  • Đáp án chỉ nhận A, B, C hoặc D.
  • CLO nhận CLO1, CLO2, CLO3; các dạng như “1”, “clo 1” được tự chuẩn hóa.
  • Mã đề trống hoặc trùng sẽ được cảnh báo.
Nếu đề không đánh giá CLO, có thể để trống cột CLO; hệ thống vẫn tính điểm tổng theo thang 10.

3. Đọc dữ liệu và chấm bài

Sau khi chuẩn bị dữ liệu, nhấn Đọc dữ liệu và chấm bài.

File UnT → Đọc đáp án/mã đề → Kiểm tra dữ liệu → Chấm từng bài → Tính GPA/CLO → Chuẩn bị file xuất

Câu bỏ trống hoặc chọn nhiều đáp án được tính là sai, không được xem là lỗi hệ thống.

4. Kiểm tra SBD và mã đề

Nếu phát hiện dữ liệu bất thường, công cụ sẽ yêu cầu kiểm tra trước khi tiếp tục.

  • SBD có thể chỉnh trực tiếp trên bảng xác nhận.
  • Nếu file UnT chứa ảnh số phách tại cột B, hệ thống có thể dùng ảnh đó để hỗ trợ kiểm tra SBD.
  • Mã đề không trùng với file đáp án sẽ được cảnh báo để người dùng ánh xạ hoặc sửa lại.
  • SBD rỗng, trùng hoặc không hợp lệ cần xử lý trước khi xuất.
Hãy xác nhận kỹ SBD và mã đề vì đây là hai thông tin quyết định việc ghép đúng sinh viên và đúng bộ đáp án.

5. File khảo thí

File khảo thí là tùy chọn. Khi cung cấp file này, công cụ dùng số phách để ghép kết quả vào danh sách/phòng tương ứng và giữ lại các phần thông tin đầu bảng cần thiết.

  • Có thể chứa nhiều sheet/phòng.
  • Giữ các dòng tiêu đề đầu bảng khi xuất kết quả.
  • Cột ghi chú được giữ nguyên.
  • Phách có trong danh sách nhưng chưa có bài vẫn được giữ dòng để dễ đối chiếu.

6. Xuất kết quả

Sau khi chấm thành công, ba nút xuất sẽ được mở.

FileNội dung chính
Bảng điểm pháchĐiểm theo số phách, phục vụ quy trình khảo thí.
Bảng điểm chi tiếtChi tiết bài làm, GPA và kết quả theo CLO.
Báo cáoTổng hợp phục vụ báo cáo/đánh giá theo mẫu BM33.

7. Một số lỗi thường gặp

Không nhận được file UnT

Kiểm tra file có đúng định dạng Excel và có vùng dữ liệu câu trả lời hay không.

Mã đề không có trong đáp án

Kiểm tra lại mã đề trong UnT hoặc dùng bước ánh xạ mã đề khi hệ thống yêu cầu.

Đáp án/CLO báo sai

Đáp án phải là A–D. CLO chỉ nên dùng CLO1/CLO2/CLO3 hoặc để trống nếu không áp dụng CLO.

Không xuất được file
